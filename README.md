# python-project-Millionaire-Game
A Python-based trivia quiz game inspired by "Who Wants to Be a Millionaire," featuring multiple difficulty levels, lifelines, and a prize-money scoring system.
Millionaire Quiz Game is an interactive trivia application inspired by the classic "Who Wants to Be a Millionaire" format. Players answer a series of increasingly difficult multiple-choice questions to climb the prize ladder, with classic lifelines (50:50, Ask the Audience, Phone a Friend) to help along the way.
